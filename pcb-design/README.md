# Basic PCB Design Example (LibrePCB)

This folder documents a simple PCB design example intended to demonstrate familiarity with schematic capture, component placement, and board layout concepts in LibrePCB.

## Example Concept
A simple power input and decoupling layout including:
- DC input source
- resistor load
- capacitor for decoupling
- ground return path

## Design Goals
- Keep current path simple and easy to follow
- Place decoupling capacitor close to the load
- Maintain clear routing between power and ground
- Demonstrate basic PCB organization and manufacturable layout thinking

## What this example is meant to show
This is a basic illustrative design for portfolio purposes. It demonstrates understanding of:
- schematic-to-layout workflow
- component placement
- routing basics
- decoupling considerations
- PCB design communication
